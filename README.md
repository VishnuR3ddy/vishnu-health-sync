# Vishnu Health Sync

Personal automation: pulls my own health data (steps, calories, sleep, heart rate,
Active Zone Minutes) from the Google Health API into my personal Google Sheet
every 30 minutes.

- One user (me), one Google account, read-only scopes.
- Data flow: Google Health API -> local script -> my Google Sheet. Nothing else.
- Not a public app; the OAuth client exists only to authorize my own access.
